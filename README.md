# Carom

Carom is a top-down paddle duel about spin and bank shots. Move as the ball hits to bend its flight, then use the two swaying, rotating obstacles to send it past your opponent. Play solo against the AI or share the keyboard in local versus mode.

## Install and run

```sh
npm ci
npm run dev
```

Open the local URL Vite prints. To create the static production site in `dist/`, run:

```sh
npm run build
```

## Controls

- **W / S** move the left paddle.
- **Arrow Up / Arrow Down** move the right paddle in versus mode.
- **Enter / Space** select menu items.
- **P / Escape** pause or resume.
- **M** toggle sound.

In solo mode the arrow keys also move the left paddle; the right paddle is controlled by the AI. The how-to-play screen is available from the title menu.
